# 1. Création des comptes, pas à pas

Ordre conseillé : **Gmail → YouTube → Facebook (page) → Instagram → TikTok**, car YouTube dépend du compte Google, et Instagram se relie à la page Facebook.

Préparez avant de commencer :
- votre téléphone (vérification par SMS pour chaque plateforme) ;
- les textes du fichier [02-branding-et-bios.md](02-branding-et-bios.md) ouverts dans un onglet ;
- un logo carré (1024×1024 px) et une bannière (2048×1152 px) — le fichier `icon.svg` du site peut servir de base.

---

## Étape 1 — Compte Gmail (~10 min)

1. Ouvrez [accounts.google.com/signup](https://accounts.google.com/signup).
2. Nom : `L'Atelier` / `des Maths` (ou votre vrai nom si vous préférez que le compte soit personnel).
3. Adresse suggérée (testez dans cet ordre selon disponibilité) :
   - `latelierdesmaths@gmail.com`
   - `atelier.des.maths@gmail.com`
   - `latelierdesmaths.officiel@gmail.com`
4. Mot de passe : long et unique (gestionnaire de mots de passe recommandé).
5. Vérifiez par SMS, ajoutez `guerch.karim@gmail.com` comme adresse de récupération.
6. Activez la **validation en deux étapes** (Sécurité → Validation en deux étapes) — indispensable, ce compte va porter toute la chaîne.

## Étape 2 — Chaîne YouTube (~15 min)

1. Connecté avec le nouveau Gmail, allez sur [youtube.com](https://youtube.com) → avatar → **Créer une chaîne**.
2. Nom de la chaîne : `L'Atelier des Maths`. Identifiant : `@latelierdesmaths`.
3. Dans [YouTube Studio](https://studio.youtube.com) → Personnalisation :
   - photo de profil (logo 1024×1024), bannière (2048×1152) ;
   - description : copier depuis `02-branding-et-bios.md` ;
   - liens : le site `https://guerchkarim.github.io`, puis TikTok/Insta/Facebook une fois créés.
4. Studio → Paramètres → Chaîne → **mots-clés** : `maths, mathématiques, primaire, collège, lycée, cours, exercices, brevet, bac`.
5. Vérifiez le compte par téléphone (Studio → Paramètres → Chaîne → Éligibilité) : cela débloque les miniatures personnalisées et les vidéos > 15 min.
6. Créez dès maintenant les **playlists** : `Primaire (CP–CM2)`, `Collège (6e–3e)`, `Lycée (2de–Terminale)`, `Astuces en 60 secondes`.

## Étape 3 — Page Facebook (~10 min)

1. Connectez-vous à votre compte Facebook personnel (ou créez-en un — une page doit être administrée par un profil).
2. Allez sur [facebook.com/pages/create](https://www.facebook.com/pages/create).
3. Nom : `L'Atelier des Maths` — Catégorie : `Éducation` — Bio : copier depuis `02-branding-et-bios.md`.
4. Ajoutez logo + bannière, le site web, et l'adresse Gmail créée à l'étape 1.
5. Créez le nom d'utilisateur de la page : `@latelierdesmaths` (Paramètres → Nom d'utilisateur).

## Étape 4 — Compte Instagram (~10 min)

1. Sur l'application Instagram : **Créer un compte**, avec l'adresse Gmail de l'étape 1.
2. Nom d'utilisateur : `latelierdesmaths` (repli : `latelier.des.maths`).
3. Passez le compte en **professionnel** : Paramètres → Compte → Passer à un compte professionnel → catégorie `Éducation`.
4. Reliez-le à la page Facebook (Paramètres → Partage sur d'autres applications, ou via Meta Business Suite). **Ce lien est ce qui permettra la publication automatique simultanée Facebook + Instagram.**
5. Bio : copier depuis `02-branding-et-bios.md` ; lien : le site.

## Étape 5 — Compte TikTok (~10 min)

1. Application TikTok → **S'inscrire** avec l'adresse Gmail de l'étape 1.
2. Nom d'utilisateur : `latelierdesmaths`.
3. Paramètres → Compte → **Passer en compte professionnel** → catégorie `Éducation` (débloque les statistiques et la planification web).
4. Bio + lien vers le site : copier depuis `02-branding-et-bios.md`.

## Étape 6 — Meta Business Suite (~5 min)

1. Ouvrez [business.facebook.com](https://business.facebook.com) avec le compte qui administre la page.
2. Vérifiez que la page Facebook **et** le compte Instagram apparaissent tous les deux.
3. C'est depuis cet outil (gratuit) que se planifient les publications Facebook + Instagram — voir `05-automatisation-publication.md`.
