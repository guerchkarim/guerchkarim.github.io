# 5. Publier chaque jour, automatiquement

Objectif : vous enregistrez vos vidéos **une fois par semaine**, et elles se publient **toutes seules, chaque jour, sur les 4 réseaux**.

## La méthode recommandée (100 % gratuite) : la programmation native

Chaque plateforme sait programmer des publications à l'avance. Une session de 30–45 min le dimanche suffit pour programmer toute la semaine.

### YouTube (Shorts et vidéos longues)
1. [studio.youtube.com](https://studio.youtube.com) → **Créer** → Importer la vidéo.
2. Titre + description (avec le lien du site) + hashtags.
3. Visibilité → **Programmer** → choisir jour et heure.
4. Répétez pour les 7 vidéos : YouTube n'a aucune limite de programmation.

### Facebook + Instagram en une seule fois (Meta Business Suite)
1. [business.facebook.com](https://business.facebook.com) → **Planifier** → Créer un Reel.
2. Cochez **Facebook ET Instagram** : une seule importation publie sur les deux.
3. Description + hashtags → **Programmer** → jour et heure.
4. Le calendrier intégré montre toute la semaine d'un coup d'œil.

### TikTok
1. Sur ordinateur : [tiktok.com/tiktokstudio/upload](https://www.tiktok.com/tiktokstudio/upload) (compte professionnel requis — voir guide 1).
2. Importez la vidéo, description + hashtags.
3. **Programmer** : jusqu'à 10 jours à l'avance.

### Heure de publication conseillée
**17 h 30 – 19 h en semaine** (sortie des cours), **11 h le week-end**. Gardez la même heure tous les jours : la régularité est un signal fort pour les algorithmes et une habitude pour l'audience.

## Option « un seul tableau de bord » : Metricool (ou Buffer)

Si programmer sur 3 interfaces vous pèse :
- **[Metricool](https://metricool.com)** (interface en français) : plan gratuit ≈ 50 publications/mois sur YouTube, TikTok, Instagram, Facebook — suffisant pour 1/jour. Vous importez la vidéo une fois, cochez les 4 réseaux, choisissez les horaires : terminé.
- **[Buffer](https://buffer.com)** : équivalent, plan gratuit limité à 3 réseaux connectés.
- À plus grande échelle : Metricool payant (~12 €/mois) ou Later, Hootsuite, etc.

⚠️ Connectez toujours ces outils par le bouton officiel « Se connecter avec Google/Facebook/TikTok » (OAuth). Ne donnez jamais votre mot de passe à un outil qui le demande directement.

## Option avancée (plus tard) : automatisation par API

Quand la chaîne tournera, on pourra brancher une vraie chaîne automatisée :
- **n8n** (auto-hébergeable, gratuit) ou **Make/Zapier** : un dossier Google Drive « À publier » → chaque jour à 17 h 30, le scénario prend la vidéo du jour et la publie via les API YouTube et Meta.
- L'API YouTube est gratuite ; l'API de publication Instagram/Facebook demande une app Meta (gratuite, vérification simple) ; TikTok a une API de publication ouverte aux comptes professionnels.
- Je peux vous construire ce scénario (scripts + guide de branchement) quand les comptes existeront — demandez-le-moi à ce moment-là.

À savoir : les plateformes favorisent les vidéos importées nativement ou via partenaires officiels (Metricool/Buffer le sont). Évitez tout outil qui « simule » un humain, c'est le meilleur moyen de faire bannir les comptes.

## Votre routine hebdomadaire (≈ 3 h 30 le dimanche)

| Durée | Tâche |
|---|---|
| 2 h – 2 h 30 | Enregistrer les 7 vidéos de la semaine (scripts prêts la veille) |
| 30 min | Montage rapide CapCut (couper, texte à l'écran, export 1080×1920) |
| 30–45 min | Programmer : YouTube Studio, Meta Business Suite, TikTok Studio |
| 10 min | Répondre aux commentaires de la semaine passée (les défis en génèrent — répondez-y, l'algorithme adore) |

Le reste de la semaine : **zéro obligation**. Tout part tout seul.
